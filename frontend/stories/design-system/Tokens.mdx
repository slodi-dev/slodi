# Tokens

Generated from `app/slodi-tokens.css` every time Storybook builds — there is no
hand-copied value on this page. Each value is resolved through its `var()` chain the way
the browser's cascade does it on `<html>`: **Light** is the `:root` blocks, **Dark** adds the
`:root.dark, [data-theme="dark"]` blocks that the in-app toggle triggers. `@media
(prefers-color-scheme)` blocks are skipped, because they follow the OS rather than the
toggle.

A red ⚠ marks a token that points at an undeclared name or resolves to an invalid value.

## Component colour tokens

Form controls (text fields, textareas, selects, search, comboboxes) take their edge from
`--sl-input-border*`, which sits on `--sl-color-border-strong` so the only boundary of the
control clears 3:1 (WCAG 1.4.11). `--sl-color-border` is for cards and dividers. See
**Design system / Form controls** for every state measured live.

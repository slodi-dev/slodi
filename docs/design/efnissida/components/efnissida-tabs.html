EfnissidaTabs

Yfirlit · Leiðbeiningar · Búnaður · Athugasemdir. Reshaped from ProgramDetailTabs.

A real ARIA tablist: one tab stop for the strip, arrow keys between tabs, Home/End, aria-selected and aria-controls. Panel headings are kind-aware — „Um verkefnið", never „Um dagskrána" on a Verkefni. An empty tab is dimmed and states why rather than vanishing, because a tab set that changes length between items is harder to learn than a disabled tab.

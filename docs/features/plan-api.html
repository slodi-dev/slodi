Slóði plan API

The endpoints the frontend can build the Vinnubekkur on. Draft, 16. nóvember 2026. Built on the data model in docs/features/data-model.html. Nothing here exists yet unless it says so.

The idea in four lines

  • Content is the thing itself (Slit, Ratleikur, Fundur um hnúta). It has a level: 0 verkefni, 1 viðburður/fundur, 2 dagskrá, 3 starfsár.
  • Placement puts content inside another placement at a time. Slit is one content placed in 30 fundir. Editing Slit changes it in all of them.
  • Workspace holds content, placements and units. The bank, a plan and a scratchpad are all workspaces.
  • Unit is any group (deild, sveit, flokkur…). A placement can be for some units.

Conventions

  • Times are ISO 8601 with an offset, e.g. 2026-10-14T18:00:00Z. Iceland has no daylight saving, so it is always Z.
  • Lists are flat and carry parent_id. The frontend builds the structure.
  • An empty list is [] with 200, never 404.
  • Errors: 404 not found or no access, 403 can read but not edit, 409 the change breaks a rule (the message says which), 422 invalid body.
  • Reading needs workspace membership (the bank: any signed-in user). Changing anything needs the editor role or above.
  • Creating returns 201 and a Location header.

Shapes

type ContentLevel = 0 | 1 | 2 | 3;   // task, event, program, season

// Short form, embedded in every placement so a fundur draws in one call.
type ContentSummary = {
  id: string;
  level: ContentLevel;
  name: string;
  duration_min: number | null;      // the bank's estimate, minutes
  duration_max: number | null;
  location: string | null;
  tags: string[];
  equipment: string[];               // summed per week for the Rist's Innkaup column
  times_used: number;                // placements of it plus copies made from it
  hidden: boolean;                   // hidden by a moderator: draw a greyed gap
};

type Placement = {
  id: string;
  workspace_id: string;
  parent_id: string | null;          // the placement that holds this one
  content: ContentSummary;
  starts_at: string;                 // always set
  ends_at: string;                   // always set
  time_set: boolean;                 // false: the frontend chose it, hide the time
  unit_ids: string[];                // empty: for whoever the parent is for
};

type Unit = {
  id: string;
  workspace_id: string;
  parent_id: string | null;          // the unit that holds this one
  name: string;
  color: string;                     // "#rrggbb", always set
  deleted_at: string | null;         // set on deleted units, which older placements may still name
};

Full content (ContentOut) is as today with level in place of content_type, and a new copied_from_id: string | null.

Content

GET/workspaces/{id}/content

Exists. The bank grid and search, with every filter it has today. New: a level filter, a list like age and tags, so ?level=0&level=1 gives only verkefni and fundir. Each item gets times_used: placements of it plus copies made from it („Notað N sinnum“).

POST/workspaces/{id}/content

Body as today plus level, with tag_names for tags. Replaces the three create routes for programs, events and tasks.

GET/content/{id}

Exists. Full content with comments.

PATCH/content/{id}

Any field. Changing level while the content is placed gives 409 if it would break the level rule.

DELETE/content/{id}

Also removes its placements and everything placed under them.

Copying into a workspace

Used for “take this from the bank” and for moving a plan from a scratchpad to another workspace. Copying brings the content and, if it has one, its structure (the content's own placement and everything under it).

GET/workspaces/{id}/copies/preview?source_id=…

Which pieces you already have copies of, so the frontend can ask „Nota þitt eða nýtt afrit?“ per piece.

{ already_have: { source_id: string; existing_id: string; name: string }[] }
POST/workspaces/{id}/copies 
{
  source_id: string;
  reuse: Record<string, string>;   // source_id → your existing_id; anything not listed is copied fresh
  parent_id?: string;               // place it inside this placement
  starts_at?: string;               // shifted in whole weeks to this date, keeping weekdays
}
→ 201 { content: ContentOut; placements: Placement[] }

Copy, and optionally place. Without parent_id the copy sits on its own in the workspace, keeping its layout. With it, the copy goes straight inside that placement, in one call, so a failed drag never leaves half a copy.

Placements

Every view opens one structure: one placement and the content under it. Nothing is drawn from „everything in the workspace on these dates“. Content that isn't inside the structure you opened is simply not in that view, so an unplanned copy needs no flag. The views don't assume a starfsár at the top: any level can be opened.

GET/workspaces/{id}/placements?top=…&level=…&from=…&to=…

For finding something to open, not for drawing. All filters optional: top=true only placements with no parent, level=1 only fundir, from–to what overlaps the range. Each carries its content summary and parent_id, so the frontend can show where it sits.

GET/placements/{id}?from=…&to=…&level=…

Opens any placement, wherever it sits: a fundur inside a dagskrá inside a starfsár opens on its own. Returns the placement and everything under it, flat. Filters optional: from–to keeps what overlaps the range (with what it holds), level=1 only the fundir. One fundur sheet, a bank idea's layout, or a whole starfsár for Bekkurinn, Rist, Dagatal, the timeline and the window.

POST/workspaces/{id}/placements 
{
  content_id: string;               // content in this workspace
  parent_id?: string;
  starts_at: string;
  ends_at?: string;                 // default: starts_at + duration_min, else a default by level
  time_set?: boolean;               // default false
  unit_ids?: string[];
}
→ 201 Placement

Default lengths when the content has no duration_min: verkefni 15 min, fundur 90 min, dagskrá 4 weeks, starfsár 36 weeks.

409 if the content's level isn't lower than the parent's, or the content or parent is in another workspace.

PATCH/placements/{id}

Any of starts_at, ends_at, time_set, parent_id, unit_ids. A new starts_at moves everything under it by the same amount; a new ends_at alone resizes and moves nothing. Returns the placement and everything under it.

PATCH/placements 
[{ id: string; starts_at?: string; ends_at?: string; parent_id?: string; time_set?: boolean; unit_ids?: string[] }]
→ 200 Placement[]

Several changes as one: all or none. Reordering a fundur moves one verkefni and shifts the ones after it in one call.

DELETE/placements/{id}

Removes it and everything under it. The content stays.

POST/placements/{id}/copies 
{ starts_at: string[]; parent_id?: string }   // e.g. every Tuesday until May
→ 201 Placement[]   // the new top placements

“Copy weekly”. Each copy gets its own placements under it; the content is shared, not copied.

POST/placements/{id}/own-version

Copies this placement's content and points the placement at the copy, so editing it no longer changes the other places. Returns the placement.

Units

A placement has no colour of its own. The frontend shows its unit's colour: with one unit, that unit's; with several or none, the nearest parent placement's, or neutral.

GET/workspaces/{id}/units?include_deleted=…

All units, flat. include_deleted=true adds deleted ones, so an older plan can still show who it was for.

POST/workspaces/{id}/units 
{ name: string; parent_id?: string; color?: string }   // color defaults from a palette
→ 201 Unit
PATCH/units/{id}

Any of name, parent_id, color. 409 if the move would put a unit inside itself.

DELETE/units/{id}

Soft delete: the unit and the units under it disappear from lists and can't be put on new placements, but placements that already name them keep them.

Unchanged

Comments, likes, tags (tag_names on create and edit), reports, Yfirferð, workspaces and members. Yfirferð will only show content from the bank workspace.

What the frontend contract on release/vinnubekkur-v1 should drop

  • Season and its kind: a starfsár is level-3 content, a scratchpad is a workspace.
  • GET /seasons/{id}/grid: use the placements list.
  • EventType, scope, status and the “?” marker: type is a tag, scope comes from unit_ids, status is not in v1.
  • week_index, span_weeks, planned_minutes: every placement has real times.
  • Fixed bands (opnun, kjarni, lok) and slot kinds: tags, ordered by time.
  • Endurmat as a field: it is a comment on the content.
  • Patrol.accent: Unit.color.
